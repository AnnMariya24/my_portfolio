## 🚀 Local Development & Preview

To run and preview the website locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AnnMariya24/my_portfolio.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd my_portfolio
   ```
3. **Open in browser:**
   - Double-click [`index.html`](index.html) in your file explorer, OR
   - Use VS Code's **Live Server** extension, OR
   - Run a quick local server with Python:
     ```bash
     python -m http.server 8000
     ```
     and open `http://localhost:8000` in your browser.

## 🌐 Deployment (GitHub Pages)

This website is configured for zero-build deployment via GitHub Pages:

1. Go to repository **Settings** → **Pages**.
2. Under **Build and deployment > Branch**, select `main` and `/ (root)`.
3. Click **Save**.
4. Live site URL: **[https://annmariya24.github.io/my_portfolio/](https://annmariya24.github.io/my_portfolio/)**
